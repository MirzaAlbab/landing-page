# landing-page

A static landing page demonstrating a business presentation layout.

[Repository](https://github.com/MirzaAlbab/landing-page)

## Features

- Landing page markup in index.html
- Custom stylesheet and local image assets
- Published demo linked from the original repository documentation

## Technology

HTML and CSS

## Getting started

Clone the repository and serve the root directory with a local static web server. For example, with Python 3:

```bash
git clone https://github.com/MirzaAlbab/landing-page.git
cd landing-page
```

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). Keep the relative directory layout intact so styles, scripts, and images resolve correctly.

## Development and checks

Check page navigation, responsive layouts, browser console errors, and missing assets in a browser. No root automated test runner is configured.
